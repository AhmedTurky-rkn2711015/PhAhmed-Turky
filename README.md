إتقان الوقت — برايان تريسي

تطبيق Android تعليمي تفاعلي باللغة العربية يساعد على بناء عادات أفضل في إدارة الوقت والإنتاجية. يجمع التطبيق بين منهج تعليمي قصير، واختبارات اختيار من متعدد، وأدوات عملية للتخطيط والتركيز، مع نظام نقاط وإنجازات لمتابعة التقدم.


ملاحظة: هذا المشروع يقدّم تطبيقًا محليًا تجريبيًا للتعلم والإنتاجية. البيانات تُخزّن على الجهاز، ولا يتضمن المستودع نظام حسابات أو خادمًا خاصًا بالمستخدمين.

المزايا

•
منهج تعليمي: وحدات حول تنظيم بيئة العمل، التخطيط، ترتيب الأولويات، التركيز، وتقنيات الإنتاجية.

•
اختبارات قصيرة: اختبار لكل وحدة مع درجة نجاح مقدارها 60% وشرح للإجابات.

•
أدوات عملية:

•
تصنيف المهام وفق نظام ABCDE.

•
مؤقت جلسات التركيز.

•
تقسيم المشاريع إلى خطوات صغيرة وفق تقنية Salami Slicing.

•
تسجيل الوقت الضائع وتحويله إلى فرص للتعلم.



•
تقارير الأداء: عرض دقائق التركيز، الوقت المُسجّل، المهام المكتملة، وتقدم الوحدات.

•
التلعيب: نقاط XP، سلسلة نشاط، أوسمة، ولوحة متصدرين محلية.

•
الإشعارات: مركز إشعارات داخل التطبيق وإعدادات للتذكيرات.

•
واجهة عربية RTL: الواجهة مضبوطة من نقطة التشغيل لتدعم اتجاه الكتابة من اليمين إلى اليسار.

•
بيانات ابتدائية: عند أول تشغيل تُضاف أمثلة إرشادية للمهام والمشاريع وسجل الوقت الضائع.

├── data/
│   ├── database/       # Room database وDAO والكيانات
│   ├── model/          # نماذج المنهج والتلعيب والإشعارات

التشغيل محليًا

1.
استنسخ المستودع وافتح مجلده في Android Studio:

Bash


git clone <repository-url>
cd PhAhmed-Turky-main





2.
نفّذ Gradle Sync وانتظر اكتمال تنزيل الاعتمادات.

3.
شغّل التطبيق على محاكي أو جهاز Android بإصدار API 24 أو أحدث.

من سطر الأوامر، إذا كان Gradle مثبتًا على جهازك:

Bash


gradle assembleDebug
gradle test



ينتج ملف APK التجريبي داخل:

Plain Text


app/build/outputs/apk/debug/app-debug.apk






لا يحتوي الأرشيف الحالي على ملف gradlew التنفيذي؛ لذلك استخدم Gradle المثبت محليًا أو افتح المشروع عبر Android Studio، أو أضف Gradle Wrapper قبل مشاركة المستودع مع فريق آخر.

إعداد Gemini وFirebase

يحتوي المشروع على إعدادات Gradle لاعتماد Firebase AI، إضافة إلى Secrets Gradle Plugin. ملف .env.example يوضح مكان إعداد مفتاح Gemini:

Plain Text


GEMINI_API_KEY=MY_GEMINI_API_KEY



للاستخدام المحلي:

1.
انسخ .env.example إلى ملف .env.

2.
أزل علامة التعليق من GEMINI_API_KEY وأدخل مفتاحك.

3.
لا ترفع .env أو أي مفتاح سري إلى Git.

4.
إذا احتاج مشروعك إلى Firebase فعليًا، أضف ملف google-services.json إلى مجلد app/ وفق إعدادات مشروع Firebase لديك.

يُرجى مراجعة استدعاءات Gemini الفعلية قبل اعتبار المفتاح مطلوبًا للتشغيل؛ الاعتماد موجود في إعدادات Gradle، بينما تعمل وظائف المنهج والتخزين المحلي دون خادم.

ملاحظات التطوير

•
الحزمة الحالية هي com.example، ومعرّف التطبيق هو com.aistudio.timemastery.btracy. غيّرهما قبل نشر التطبيق تجاريًا.

•
إعداد الإصدار release يتوقع متغيرات البيئة KEYSTORE_PATH وSTORE_PASSWORD وKEY_PASSWORD، إضافة إلى مفتاح توقيع باسم upload.

•
بيانات المستخدم الافتراضية تُنشأ مرة واحدة عند غياب سجل الإحصاءات، وتشمل مهمة ABCDE ومشروعًا مقسمًا إلى شرائح وسجلًا للوقت الضائع.

•
يجب طلب إذن الإشعارات على Android 13 أو أحدث إذا أضيفت جدولة إشعارات فعلية إلى مسار الاستخدام.
